# Dice Game

The Dice Game is a fun and interactive web-based game built with **React.js**. Players roll dice to compete and determine the winner based on the dice outcomes.

## Features

- **Dice Rolling:** Randomly generates dice results for players.
- **Interactive UI:** Smooth and responsive user interface.
- **Winning Logic:** Automatically determines the winner based on dice values.

## Technologies Used

- **Frontend:** React.js
